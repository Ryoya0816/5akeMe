# 診断ロジック「約100人分」仮計算まとめ

コード・ダミーデータは使わず、現在の設定とロジックだけから「100人くらいが受けたらどうなるか」を整理したメモです。

---

## 1. 現在のロジックの要点

- **出題**: 必ず5問。**q1**（今日の気分）→ **q2**（お酒に求めるもの）→ **A/B/C から各1問ランダム**（例: A3, B1, C5）。
- **q1**: スコアには使わない。**mood**（lively / chill / silent / light / strong）の決定だけ。
- **q2**: スコアに使う。しかも **1.5倍**（`q2_multiplier`）で効く。
- **A/B/C の1問ずつ**: それぞれ config の `weights` の「質問ID:選択肢」で加点。
- **結果の出し方**: 全10タイプの合計スコアを出し、「最大スコアとの差が 5 点以内」のタイプを候補にする。その中で**いちばんスコアが高いタイプ**が **primary**（診断結果として表示されるタイプ）。

つまり「誰が何を選んでも」、  
**q2 の影響が強く**（1.5倍）、その上で **ランダムで選ばれた A・B・C 各1問の答え** が積み上がって、10種類のどれか1つが primary になる、という動きです。

---

## 2. 10種類のタイプと「出やすさ」のイメージ

weights の配分と「どの質問・選択肢で強く加点されるか」から、約100人いたときの**おおよその傾向**だけ書きます（数値はコードで回していないので「感覚的な目安」です）。

| 診断結果（primary） | 出やすさの目安 | どんな答えの流れで出やすいか（イメージ） |
|--------------------|----------------|------------------------------------------|
| **クラフトビール** | やや多め | q2「香り」、わいわい・ガンガン・仕事終わり・テンション高め系の A/C の a,b 選択。 |
| **白ワイン** | やや多め | q2「飲みやすさ」「香り」、軽め・甘め・明るい系の B/C の a,b 選択。 |
| **カクテル** | やや多め | q2「飲みやすさ」、主役・直感・面白い人・甘め・カウンター系の A/B/C の a 寄り。 |
| **日本酒・辛口** | 普通 | q2「スッキリ感」「料理との相性」、理性・落ち着き・様子見・辛口寄りの A/B。 |
| **日本酒・甘口** | 普通 | q2「飲みやすさ」、優しい人・甘め・軽め系の A/B の a,b 選択。 |
| **赤ワイン** | 普通 | 様子見・裏方・落ち着いた・暗め・重め・肉料理系の A/B/C の c〜e 寄り。 |
| **ウイスキー** | 普通 | 静観・影・理性・一人・個室・重め系の A/B/C の d,e 選択。 |
| **焼酎・芋** | やや少なめ | 一人・暗い・相棒・クセ強・重め系の A/B/C の e 寄り。 |
| **焼酎・米** | 少なめ | 裏方・理性・刺身・スッキリ・落ち着き系の A/B の c,d 寄り。 |
| **焼酎・麦** | 少なめ | 中間・軽め・家飲み・水割り・ほどほど系の B/C の b,c 寄り。 |

※「出やすさ」は、weights で **高得点が付く選択肢が a,b に多いか / c,d,e に多いか** と、**q2 で一気に伸びるタイプがどれか** からざっくりつけています。

---

## 3. 約100人分を仮に考えたときの「結果の内訳」イメージ

上記の「出やすさ」と、  
「q2 が強く効く」「A/B/C はランダムなので人によって効く質問が違う」「候補幅 5 点なので同点・ニア同点で別タイプが primary になりうる」  
を合わせて、**100人ならだいたいこんな割合になりそう**という目安です（あくまで感覚値）。

| 診断結果（primary） | おおよその人数の目安（100人中） |
|--------------------|----------------------------------|
| クラフトビール | 約 12〜18 人 |
| 白ワイン | 約 10〜15 人 |
| カクテル | 約 10〜14 人 |
| 日本酒・辛口 | 約 8〜12 人 |
| 日本酒・甘口 | 約 8〜12 人 |
| 赤ワイン | 約 8〜12 人 |
| ウイスキー | 約 8〜12 人 |
| 焼酎・芋 | 約 6〜10 人 |
| 焼酎・米 | 約 4〜8 人 |
| 焼酎・麦 | 約 4〜8 人 |

- **10種類すべて**、何らかの答えの組み合わせで primary になり得るので、**0人になるタイプはない**想定。
- **クラフトビール・白ワイン・カクテル** は、q2 や A/B/C の「前の方の選択肢（a,b）」でよく加点されるため、やや多め。
- **焼酎・米 / 焼酎・麦** は、特定の「落ち着き・中間・軽め」の組み合わせでないとトップになりにくいため、少なめ、というイメージです。

---

## 4. 補足（mood・候補・同点）

- **mood** は q1 だけで決まるので、「診断結果（primary）のタイプ」とは独立。「約100人」の primary の分布には q1 は効きません。
- **候補**（最大との差 5 点以内）は、primary 以外にも 2〜3 タイプ入ることがよくある、という設計です。
- 同点やニア同点のときは、**スコア降順の先頭**が primary になるので、weights の並びや「fill」の優先順（日本酒・米焼酎・白ワインなど）が少し効きます。

---

## 5. まとめ（一言）

- 今のロジックのまま「約100人分」を仮に考えると、**10種類どれも出る**が、  
  **クラフトビール・白ワイン・カクテルがやや多め**、**焼酎・米／焼酎・麦がやや少なめ**になる、というイメージです。
- 実際の分布は「どの A/B/C が何回出たか」「ユーザーが a〜e をどう選ぶか」で変わるので、あくまで **現行設定からの傾向のまとめ** として読んでください。
