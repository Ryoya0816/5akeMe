## セキュリティ・品質

| 項目 | 内容 |
|------|------|
| **認証** | Breeze（セッション） + Socialite（OAuth） |
| **管理画面** | Filament + 管理者フラグ（is_admin） |
| **アカウント停止** | is_active フラグ + ログインブロック |
| **CSP** | Content-Security-Policy ヘッダー |
| **CSRF** | Laravel標準トークン |
| **レート制限** | 通報 5回/分、API 30回/分 |
| **テスト** | PHPUnit（Feature / Unit）、25テスト |

## 本番デプロイ想定

- **サーバー**: VPS（例: ConoHa / さくら）またはクラウド
- **OS**: Ubuntu 22.04+
- **Web**: Nginx + PHP-FPM または Docker
- **DB**: MySQL 8.0
- **SSL**: Let's Encrypt（推奨）
- **手順**: `DEPLOYMENT.md` 参照
