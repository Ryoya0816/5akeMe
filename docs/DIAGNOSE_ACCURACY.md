# 診断精度の向上について

## いまの仕組み（要約）

- **質問**: 固定2問（q1 気分 / q2 お酒に求めるもの）+ カテゴリ A/B/C から各1問ランダム → 計5問
- **スコア**: `config/diagnose.weights` の `"質問ID:選択肢"` ごとにタイプ別加点。q2 は 1.5 倍。
- **結果**: 最大スコアが primary。最大との差が `candidate_width`（5点）以内が候補。
- **フィードバック**: 結果画面で 1〜5 点 + コメント。`answers_snapshot` / `result_type` / `mood` を保存済み。

---

## 精度向上の候補

### 1. フィードバックを分析してウェイトを調整する（おすすめ）

**やること**: 低評価（1〜2点）の「回答パターン + 出た結果」を集計し、  
「この回答のときにこのタイプを出しすぎている」という組み合わせを特定。  
`config/diagnose.weights` の該当するキーの点数を下げる or 別タイプを上げる。

**進め方**:
- Filament の診断フィードバック一覧で、評価が低いものの `answers_snapshot` と `result_type` を眺める。
- または Artisan コマンドで「低評価が多い result_type × よくある answers_snapshot」を集計する（後述の `diagnose:feedback-stats` を参照）。

**効果**: データに基づいてウェイトをいじれるので、精度向上に直結しやすい。

---

### 2. 固定質問を1問増やす（「ストレートに効く」質問）

**やること**: 固定3問目を追加し、タイプの切り分けに直結する質問にする。

例:
- 「辛口と甘口、どちらが好き？」→ 日本酒・辛口 vs 日本酒・甘口
- 「普段よく飲むのは？」→ ビール / ワイン / 日本酒 / 焼酎 / カクテル・ウイスキー など

**効果**: 5問→6問になるが、1問で primary の振れがかなり絞れる。  
**注意**: `config/diagnose.php` の `fixed_questions` と `weights` に追加が必要。

---

### 3. スコア計算のパラメータをいじる

| パラメータ | 現在 | 変更例 | 効果 |
|-----------|------|--------|------|
| `q2_multiplier` | 1.5 | 1.2〜1.8 | q2（お酒に求めるもの）の効き目を弱く/強くする |
| `candidate_width` | 5 | 3〜4 | 候補を絞り、1位をはっきりさせる |

**効果**: 設定だけなので手軽。フィードバックで「候補が多すぎてピンとこない」という声があれば `candidate_width` を小さくするのが有効。

---

### 4. Python API（機械学習）でスコアを出す

**いま**: PHP のウェイト加算がメイン。Python API は失敗時は PHP にフォールバック。  
**やること**: Python 側で「回答 → タイプ」のモデル（例: ロジスティック回帰や軽い NN）を学習させ、  
フィードバック（高評価 = 正解に近い）を教師データとして使う。

**効果**: 理論上は一番伸ばしやすいが、学習パイプライン・評価・本番運用の工数は大きい。

---

### 5. 低評価時に「本当はどれが近かったか」を聞く（オプション）

**やること**: 評価が 1〜2 のときだけ「当てはまったタイプ」を選んでもらう（複数選択可）。  
その選択を「正解」として保存し、のちにウェイト調整や Python の教師データに使う。

**効果**: なぜ外れたかが分かり、精度改善の根拠ができる。

---

## まず試すなら

1. **すぐできる**: `candidate_width` を 5 → 4 や 3 に変更して、1位をはっきりさせる。（※ すでに 4 に変更済み）
2. **データを見る**: 次で低評価の傾向を確認する。
   ```bash
   php artisan diagnose:feedback-stats
   php artisan diagnose:feedback-stats --detail --limit=20   # 低評価の回答スナップショットを20件表示
   ```
3. **質問を足す**: 固定3問目で「辛口 vs 甘口」など、タイプに直結する1問を追加。

必要なら、「固定3問目の追加」の具体的なコード案も書けます。
